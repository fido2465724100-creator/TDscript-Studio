# 🛠️ TDscript Studio (Desktop & Mobile IDE)

Кроссплатформенная интегрированная среда разработки (IDE) и эмуляции для языка **TDscript Core 1.1**.

## Архитектура
* **`:common-editor`**: ядро редактора кода, двусторонний проектор языков (`CodeProjector`), компилятор в `.tbc`, встроенная песочница симуляции оборудования (`AiHardwareSandbox`) и генератор машиночитаемой AI-диагностики (`StudioAiDiagnostics`).
* **`:desktopApp`**: десктопное приложение для Linux и Windows с поддержкой прямых COM-портов, USB-Serial и симулятора.
* **`:androidApp`**: мобильная редакция среды для смартфонов с поддержкой USB-OTG и BLE.

## Возможности
1. **Проекция на 109 языков на лету**: пишите `пусть`, `если`, `пока` на родном языке, код сохраняется в канонический детерминированный вид без порчи строк и комментариев.
2. **Аппаратная песочница AI Sandbox**: безопасная отладка датчиков (Bosch BME280) и контроллеров (Modbus PLC) без риска повреждения реального железа.
3. **Гранулярная изоляция `CapabilityScope`**: защита шин I2C, SPI, UART и Modbus.
